Java - Estruturas Sequenciais
📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Java com foco na utilização de estruturas sequenciais para a resolução de problemas computacionais e no desenvolvimento da lógica de programação.

📂 Conteúdo

O repositório contém exercícios sobre:

Estruturas sequenciais;
Declaração e utilização de variáveis;
Operadores aritméticos, relacionais e lógicos;
Entrada e saída de dados;
Desenvolvimento da lógica de programação.
💻 Tecnologias
Java
JDK (Java Development Kit)
▶️ Como executar
Instale o JDK em seu computador.
Clone este repositório ou faça o download dos arquivos.
Acesse a pasta onde está localizado o arquivo .java.
Compile o arquivo pelo terminal:
javac NomeDoArquivo.java

Execute o programa:
java NomeDoArquivo
