# Java - Estruturas Sequenciais

## 📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Java com foco na utilização de estruturas sequenciais para a resolução de problemas computacionais.

Os exercícios têm como objetivo desenvolver os fundamentos da lógica de programação, trabalhando com entrada e saída de dados, declaração de variáveis, tipos de dados e operações básicas.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Entrada e saída de dados;
- Operações aritméticas;
- Variáveis e tipos de dados;
- Resolução de problemas utilizando estruturas sequenciais.

## 💻 Tecnologias

- Java
- JDK (Java Development Kit)

## ▶️ Como executar

1. Instale o JDK em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Execute o arquivo desejado pelo terminal:

```bash
javac NomeDoArquivo.java
```
